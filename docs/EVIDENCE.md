# 版本与实验记录对应关系

公开证据索引为 `docs/evidence_index.json`。每条记录绑定模型、BOOT、数据、配置和分析文件身份，数值采用相应记录自身的计量口径。

## 历史真机演示

公开性能摘要采用 2026-11-04 的五分钟固定行情运行 `board_five_minutes_fixture_20261104_120716`。该运行使用 2025-12-15 AAPL 历史 MBO，按 1 倍事件间隔派发，配置为 32 个 DDR 槽、2 ms 排队年龄限制和 H50 期限。

| 项目 | 实验结果 |
|---|---|
| 原始测量事件 | 114,526 条 |
| 推理机会 | 107,174 次 |
| 完成预测 | 79,029 次 |
| 5 ms 内完成 | 78,970 次，占全部机会 73.6839% |
| 事件计划到达至上位机收到预测的均值 | 651.373 μs |
| 同口径 P99 | 1,753.874 μs |
| DDR 队列峰值 | 32 槽 |

这组指标绑定 BOOT 哈希 `b02313e7d993fba78ea3e1b58480122b5bb26fa20d343c50765de27683e3e4d0`。索引同时保存原分析 JSON、运行清单和板端运行包的 SHA256，模型身份取自实际运行包中的 `config.json`。

原运行引用完整 MBO 源文件。现有配套演示包使用同源的前缀裁剪副本，已逐字节核验其与完整源的对应关系。索引分别记录两种文件身份。
