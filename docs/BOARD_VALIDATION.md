# 真机验收结果

2026年11月10日，使用从开源源码完整构建的BOOT，在悟净FMQL30TAI完整版完成两组闭环验收。固件SHA256为`2f217f4677bd9fc3858c6b5a546d75e8a9640163939cc9845ed4782c66243b1e`，模型为冻结的H50原生INT8输入部署版本，板端Icraft为3.36.1。

## 验证的数据通路

```text
上位机按事件时间独立派发原始订单
  → PL千兆网口 → FPGA解析、建簿、定点归一化、INT8编码
  → 100条滑窗 → 整窗FIFO → 32槽共享DDR → 板载NPU
  → FPGA封装预测 → UDP → 上位机接收、展示和日志
```

ARM负责初始化和调度，运行过程中每窗输入和输出使用共享DDR。两组回放的CPU参考推理和Host仿真均关闭。PL链路核验为1000 Mbps、全双工，PHY接收附加延时配置为750 ps。

端到端时间从上位机计划派发时刻计算到同一台上位机收到预测UDP，包含派发、网络和板端处理。平均值和P99统计已完成预测。5 ms完成比例以全部推理机会为分母。

历史行情共107174次机会，其中79009次产生预测，2779次按H50期限取消，25386次在容量限制下拒绝接收，各项计数守恒。共81788条终态的寄存器读回与UDP结果逐字节一致。公开合成输入501次机会全部产生预测，其中500次在5 ms内完成。

## 输入与所有权核验

每组启动时验证4800字节输入的DDR读写、32个共享槽的映射，以及64次不同槽位和输入切换的真实NPU调用。各次输出与相应冻结参考逐字节一致，每次硬件完成计数增加30层。正式回放逐条核对窗口、原始事件身份、预测数据和终态计数。

本轮通过6次正常软件重启完成固件加载、会话切换和回收。最后核验新Linux启动身份、SD固件哈希、空闲控制器和SDK所有者退出。旧固件已在SD和电脑端保存回退副本。本机开源目录的默认固件已指向本次验收产物。

## 本轮修复

- 为队列启动建立独立运行标识，分别记录虚拟环境启动器和实际Python工作进程，回收时核对两者。
- 合成输入v2使用发布者编号2、内部标的编号38、09:35有效时段和硬件一致的逐条身份。界面标记为SYNTH，订单内容由代码生成。原v1输入保留CPU校验兼容。
- 新克隆CI执行686项测试，660项通过，26项因历史收据缺失跳过。五份ROM及参数文件重生成字节一致，原生行情源180条UDP事件核验通过。

当前固件的标的、日期与交易状态表在`hardware/rtl/top/g_bench_endpoint.sv`冻结。更换行情范围时，同步更新这份前端契约并重新构建固件。
